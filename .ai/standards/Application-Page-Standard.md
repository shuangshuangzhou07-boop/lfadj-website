# LFADJ Application Page Standard

## 1. Page Purpose

An Applications Page is an industry-focused page used to show the customer industries LFADJ serves, the work areas where mobile lighting equipment is used, and the lighting requirements created by those operating environments.

An Applications Page answers where and in what industry context the product is used. It is not a purchasing, product-selection, comparison, or configuration page.

## 2. Recommended Page Structure

Applications Pages must follow this section order.

### Section 1: Hero

**Purpose:** Establish the industry positioning of the page.

The Hero must include:

- Industry name
- Application positioning
- Industry-focused description
- CTA

### Section 2: Application Scenarios

**Purpose:** Show the specific industry situations in which mobile lighting equipment is used.

The section may include:

- Work areas
- Usage environments
- Project scenarios

### Section 3: Industry Lighting Requirements

**Purpose:** Explain the operating characteristics of the industry and the resulting lighting requirements.

This section must not include:

- Product-selection logic
- Cost analysis
- Configuration calculations

### Section 4: Recommended Products & Related Information

This section connects industry application intent with relevant website content without turning the Applications Page into a Product Page or Solution Page.

#### A. Recommended Products

Present only products relevant to the industry application and link them to their Product Pages. Do not duplicate detailed product specifications.

#### B. Related Solutions

Use concise text links to relevant Solution Pages. Do not reproduce Solution Page content.

#### C. Related Applications

Use concise text links to other relevant Application Pages.

## 3. Applications vs Solutions Rules

Applications and Solutions have different page responsibilities:

- **Applications answer:** Where is the product used?
- **Solutions answer:** How should customers choose?

An Applications Page must focus on industry environments, work areas, usage scenarios, and industry requirements.

A Solution Page may explain selection logic, comparisons, configuration decisions, and how customers should evaluate options.

Applications Pages and Solution Pages must not duplicate substantial content or compete for the same primary search intent.

## 4. Internal Linking Rules

Every Applications Page must include natural, relevant text links to:

- Relevant Product Pages
- Relevant Solution Pages
- Relevant Application Pages

Links must help users continue from industry context to the appropriate product, decision-support, or related-industry page. Anchor text must clearly describe the destination, and links must not point to missing, irrelevant, or misleading pages.

## 5. SEO Principles

Every Applications Page must:

- Target relevant industry keywords
- Strengthen topical authority for the industry and its mobile-lighting use cases
- Avoid keyword cannibalization with Product Pages, Solution Pages, and other Application Pages
- Maintain one page, one purpose
- Keep the primary search intent focused on industry usage scenarios
- Preserve clear semantic headings, crawlable internal links, and language integrity
