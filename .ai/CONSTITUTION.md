# LFADJ AI Development Constitution v1.0

This file is the highest rule source for AI work in this project.

## 1. Project Mission

LFADJ is a global B2B independent website built to support long-term business growth.

The project mission is to help overseas buyers understand, evaluate, and inquire about engineering mobile lighting solutions for demanding working environments.

The website must support real business outcomes, not only visual presentation.

## 2. Supreme Principle

LFADJ's final goal is not to develop a beautiful website.

The final goal is:

- Continuously obtain Google organic rankings.
- Continuously obtain real overseas inquiries.
- Ultimately convert inquiries into orders.

Any design, copy, code, page, or function must first serve:

- Google SEO
- Real overseas inquiry conversion
- Long-term brand building

If a modification cannot improve the goals above, its development priority must be reduced.

## 3. Website Positioning

LFADJ's website positioning is:

Engineering Mobile Lighting Solutions for Harsh Environments

中文定位：

复杂工况移动照明工程解决方案提供商

This positioning must remain consistent across future AI work.

## 4. AI Working Rules

Before modifying code, every AI agent must first read this Constitution.

All AI work must follow this Constitution.

If a user request conflicts with this Constitution, the AI must first explain the conflict before continuing.

Do not modify files outside the user's requested scope.

Use small iterative development.

For each task:

- Modify only the files required by the current request.
- Do not modify unrelated modules.
- Do not affect unrelated pages.
- Stop after completing the requested scope.
- Wait for the next instruction.
