# Navigation Standard

## Core Principle

LFADJ website navigation follows an industrial B2B information architecture:

- Home
- Products
- Applications
- Solutions
- Resources
- About
- Contact

Each section has a clear purpose:

- **Products:** Product categories and product detail pages.
- **Applications:** Industry application scenarios.
- **Solutions:** Customer decision guides and project solutions.
- **Resources:** Educational content, guides, and technical materials.
- **About:** Company trust, manufacturing, and corporate information.

## Desktop Navigation Pattern

Use compact cascading navigation.

Rules:

- Use two-level navigation only.
- Place primary categories on the left.
- Place secondary links on the right.
- Do not add descriptions.
- Do not add images.
- Do not add CTA buttons.
- Do not use large promotional panels.

Visual style:

- Use a compact dropdown.
- Keep the height content-driven.
- Maintain a clean industrial B2B style.
- Switch secondary links when a primary category is hovered.
- Show the active category with a subtle highlight and brand-color indicator.

## Mobile Navigation

Use accordion navigation.

Requirements:

- Keep the same information hierarchy as the desktop navigation.
- Do not introduce a different navigation structure.
- Maintain consistency between the English and Chinese navigation.

## SEO Rules

Navigation must:

- Use real, existing routes only.
- Never create fake links.
- Avoid duplicate category meanings.
- Maintain a clear hierarchy.

Examples:

- **Products:** Product → Product detail
- **Applications:** Industry → Application page
- **Solutions:** Problem/Decision → Solution page
- **Resources:** Category → Content page

## Language Rules

- English navigation must use English labels and English routes.
- Chinese navigation must use Chinese labels and Chinese routes.
- Do not mix languages.

## Maintenance Rules

Before adding navigation items:

1. Confirm the route exists.
2. Confirm the page purpose.
3. Confirm the item does not duplicate another section.
4. Update both the English and Chinese navigation.

Do not change the navigation structure without updating this standard.
