# LFADJ Image Standard V1.0

## Product Image Rules
- Size: 1200 × 1200 px
- Format: PNG and WebP
- Background: #FFFFFF
- Product area: 70% to 75%
- Shadow: consistent light gray shadow
- Margin: consistent on all sides
- Logo: do not include
- Watermark: do not include
- Crop mode: object-contain

## Naming Rules
- LF6130-main.webp
- LF6130-side.webp
- LF6130-detail-01.webp
- LF6130-night.webp
- LF6130-application.webp

## Usage
Use the same image standard for:
- Website product pages
- PDF catalogs
- SEO images
- Download center
- AI knowledge base
